# 割引ゲーム
高専祭に出す予定の割引ゲーム用リポジトリ  
初めてのGitHubを使った共同製作です。
以下のミニゲーム集だ!!!!  
**[ダウンロード](https://github.com/2025-gifu-E/bazzergame/releases/download/pre-1.0/waribikigame-pre1.0.zip)**
## つけろ!!!![製作者:rangea]
ライツアウトです。  
右スティックで選択してAで決定します。
## ゴールに入れろ!!!![製作者:Ariel]
パワーと方向を決めて、ランダムに出て来る3つのかごのどれかにボールを入れよう!  
Aボタンをおして決定だ
* パワー
* 上下方向
* 左右方向　の順番に決めるぞ
## 撃ち落とせ!!!![製作者:Syoma]
制限時間以内に丸を全部撃ち落とせ  
四角を落ち落とすと即ゲームオーバーだから気をつけろ
* 右スティックで操作
* Aボタンで撃破
* YボタンまたはLボタンで加速
* Bボタンで減速
