# クリアオーバレイ(開発者: rangea)
クリアしたときのオーバーレイテンプレイートです。
## 使用方法
`CanvasLayer`ノードにこのシーンをインスタンス化して使用します。  
スクリプトにこのシーンをCtrlボタンを押しながらドラック&ドロップをしてノード取得を行います。
```gdscript:main.gd
@onready var clearoverlay: Control = $CanvasLayer/clearoverlay
```
このようなコードが出てきます。
そしたらクリアしたときの処理(_on_body_enterdなど)に`clear_view()`関数を呼び出すとオーバレイが出てきます。タイトルに戻す処理は組み込んであるので必要ありません。  
### スコア表示
インスペクターにある`Use Score`をオンにするとクリア時にスコアを表示させることができます。スコアを設定するにはこのノードの`score`変数にString型で代入してください。  
また、インスペクターでスコア前後の文字を変えることができます。
